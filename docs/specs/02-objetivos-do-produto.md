# 2. Objetivos do Produto

## 2.1 Objetivos do MVP

- Centralizar a gestão operacional da escola piloto.
- Eliminar o uso de listas de presença em papel.
- Reduzir o uso de planilhas simples.
- Reduzir dependência de WhatsApp para informações internas.
- Permitir que professoras registrem frequência em menos de 1 minuto.
- Facilitar a gestão de alunas, professoras, modalidades, turmas e aulas.
- Permitir acompanhamento da frequência das alunas por período.
- Exibir alertas visuais de baixa frequência no painel administrativo.
- Entregar uma interface simples, intuitiva e visualmente polida.

## 2.2 Objetivos Futuros

- Evoluir para SaaS multi-escola.
- Suportar outras modalidades de dança além de ballet.
- Adicionar personalização visual por escola.
- Adicionar modo offline com sincronização automática.
- Criar acesso para responsáveis e alunas.
- Adicionar comunicação com responsáveis.
- Adicionar controle financeiro.
- Expandir relatórios e dashboards.

## 2.3 Indicadores de Sucesso

- Registro de frequência realizado em menos de 1 minuto.
- Redução do uso de papel para chamada.
- Redução do uso de planilhas para controle de frequência.
- Administração consegue identificar alunas com baixa frequência.
- Administração consegue visualizar frequência por aluna, turma e período.
- Escola piloto consegue testar versões parciais e validar o fluxo principal.

Critérios de frequência:

- Acima de 80%: bom.
- Entre 50% e 80%: atenção.
- Menor que 50%: crítico.

## 2.4 Prioridades do Projeto

As decisões do projeto devem seguir esta ordem:

1. Facilidade de uso.
2. Simplicidade.
3. Robustez.
4. Escalabilidade.
5. Aparência visual.

Sempre que houver dúvida entre uma solução simples e uma solução complexa, a solução simples deve ser escolhida, desde que não comprometa o MVP.

## 2.5 Suposições

- O MVP deve ser bom o suficiente para uso real na escola piloto.
- O sistema não precisa nascer como SaaS completo, mas não deve impedir essa evolução.
- Métricas avançadas podem evoluir depois que o fluxo principal estiver validado.
