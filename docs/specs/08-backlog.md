# 8. Backlog

## 8.1 Alta Prioridade

- Login.
- Controle de papéis: administrador e professora.
- Cadastro de professoras.
- Cadastro de alunas.
- Cadastro de responsáveis.
- Cadastro de modalidades.
- Cadastro de turmas.
- Vincular alunas a turmas.
- Vincular professoras a turmas.
- Criar aulas a partir de dia e horário.
- App mobile para professoras visualizarem suas aulas.
- Registro de frequência.
- Marcar todas como presentes.
- Salvar rascunho de chamada.
- Editar frequência após a aula.
- Aulas experimentais.
- Aulas particulares recorrentes.
- Alertas visuais de baixa frequência.
- Dashboard inicial.
- PDF inicial com relação de aulas, alunas e professoras.
- Logs de auditoria internos.

## 8.2 Média Prioridade

- Relatórios detalhados de frequência.
- Filtros avançados.
- Tela para logs de auditoria.
- Melhorias visuais no dashboard.
- Fluxo completo de conversão de experimental para regular.
- Tratamento detalhado de feriados e recessos.
- Histórico avançado por aluna.
- Permissões mais granulares.

## 8.3 Baixa Prioridade

- Personalização visual por escola.
- Acesso para responsáveis.
- Acesso para alunas.
- Comunicação com responsáveis.
- Integração com WhatsApp.
- Modo offline.
- Controle financeiro.
- Relatórios comerciais.
- SaaS multi-escola completo.
