# 7. Roadmap

## 7.1 MVP

- Login com JWT.
- Painel Administrativo Web.
- Aplicativo Mobile para professoras.
- Cadastro de professoras.
- Cadastro de alunas.
- Cadastro de responsáveis.
- Cadastro de modalidades.
- Cadastro de turmas.
- Vinculação de alunas a turmas.
- Vinculação de professoras a turmas.
- Criação de aulas por dia e horário.
- Registro de frequência.
- Rascunho de chamada.
- Edição de frequência pela professora após a aula.
- Aulas experimentais vinculadas a turmas.
- Aulas particulares recorrentes por plano fechado.
- Alertas visuais de baixa frequência no painel administrativo.
- Dashboard inicial.
- PDF inicial com relação de aulas, alunas e professoras.
- Logs de auditoria armazenados.

## 7.2 Versão 1.1

- Relatórios avançados de frequência.
- Filtros avançados em relatórios.
- Tela administrativa para logs de auditoria.
- Melhorias no dashboard.
- Fluxo mais completo de conversão de aluna experimental em regular.
- Tratamento mais refinado de feriados e recessos.

## 7.3 Versão 1.2

- Personalização visual por escola.
- Notificações internas.
- Melhorias em permissões.
- Histórico avançado por aluna.
- Exportações adicionais.

## 7.4 Versão 2.0

- Modelo SaaS multi-escola.
- Planos comerciais por escola, quantidade de alunas e recursos.
- Acesso para responsáveis.
- Acesso para alunas.
- Comunicação com responsáveis.
- Modo offline com sincronização.
- Controle financeiro.
